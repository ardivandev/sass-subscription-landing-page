# Sass Subscription Landing Page

Landing page responsif untuk produk manajemen proyek fiktif "Brainwave", dibangun menggunakan HTML, CSS, dan Bootstrap 5. Project ini dibuat sebagai bagian dari portofolio pembelajaran Front-End Development.

## ✨ Fitur

- Fully responsive (mobile, tablet, desktop)
- Navbar dengan collapse menu untuk mobile
- Section: Hero, Features, Facts, Testimonial, Pricing, FAQ, CTA, Footer
- FAQ dengan struktur konten yang konsisten antar item
- Aksesibilitas dasar: `alt` text deskriptif, `aria-label` pada ikon sosial media, `aria-hidden` pada ikon dekoratif
- CSS variable untuk warna, jadi mudah diubah tanpa cari satu-satu di file

## 🛠️ Tech Stack

- HTML5
- CSS3 (custom properties / CSS variables)
- [Bootstrap 5.3](https://getbootstrap.com/) — grid system & komponen dasar
- [Bootstrap Icons](https://icons.getbootstrap.com/)
- Google Fonts — Poppins
